# Security Policy

Maxion provides defense-in-depth protective controls for autonomous AI agents connecting over the Model Context Protocol (MCP).

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

Security and stability are core priorities for Maxion. If you discover a potential security issue, tool-call bypass, or unintended execution behavior, please report it responsibly so our team can evaluate and address it promptly.

### Where to Report
Please email vulnerability details to:
- **Email**: `security@advancedapparchitect.com` or create a private security advisory through GitHub.

### What to Include
When reporting an issue, please include:
1. Steps to reproduce the behavior (e.g., input prompts, environment context, tool definitions).
2. Expected behavior vs. observed behavior.
3. Relevant logs or telemetry snippets.

We strive to acknowledge reports within 48 hours and provide remediation updates as patches are validated through our test suites.
